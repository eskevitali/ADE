
Ты эксперт по DevOps и настройке AI-окружений.

Мы на сервере Hetzner (Ubuntu), проект ADE-V4.

Выполни следующее:

1. Проверь наличие и версии следующих инструментов:
   - Docker + Docker Compose
   - uv (Astral)
   - Python 3.11+
   - git
   - curl, wget, unzip

2. Если чего-то не хватает — установи.

3. Создай полную рекомендуемую структуру папок для ADE-V4:
   ├── ade/
   ├── frontend/
   ├── projects/
   ├── knowledge/
   ├── reviews/
   ├── governance/
   ├── docker/
   ├── scripts/
   ├── .env.example
   ├── PROJECT_RULES.md
   └── README.md

4. Создай .env.example с нужными переменными (OPENROUTER_API_KEY, XAI_API_KEY, etc.)
