# ТЕХНИЧЕСКОЕ ЗАДАНИЕ

## Приложение для быстрой отправки координат местоположения

## Цели

- Создать минималистичное приложение для экстренной отправки геолокации
- Обеспечить два способа активации: скрытый (встряхивание) и явный (ярлык)
- Монетизировать через рекламу AdMob и премиум-версию
- Предоставить быстрый доступ к отправке координат в критических ситуациях

## Пользователи

- **Основная аудитория**: люди, нуждающиеся в быстрой передаче местоположения (экстренные ситуации, встречи, безопасность)
- **Возрастная группа**: 13-65 лет (включая подростков и детей с согласия родителей)
- **Детская аудитория**: дети и подростки 13-17 лет для обеспечения безопасности и связи с родителями/опекунами
- **Технические навыки**: базовые пользователи смартфонов
- **География**: международная аудитория (англо-, немецко-, украиноязычные пользователи)
- **Особые требования**: соблюдение COPPA и других законов о защите детей при работе с несовершеннолетними пользователями

## Функции

### Основной функционал

#### Активация через ярлык приложения
- **Обычный ярлык**: стандартная иконка приложения в лаунчере
- **Мгновенная отправка**: при нажатии на ярлык координаты отправляются немедленно в фоне
- **Диалоговое окно**: после отправки автоматически открывается окно с:
  - Уведомлением об успешной отправке координат
  - Формой для ввода дополнительного сообщения (занимает 3/4 экрана)
  - Рекламным блоком AdMob (нижняя 1/4 экрана)
  - Кнопкой закрытия окна внизу

#### Скрытая активация встряхиванием
- **Фоновая работа**: отправка координат без отображения UI
- **Без диалогов**: никаких окон или уведомлений не показывается
- **Мгновенная отправка**: координаты отправляются сразу после встряхивания

#### Определение местоположения
- **GPS-координаты**: быстрое получение точных координат
- **Отображение времени**: показ времени определения местоположения
- **Адрес**: преобразование координат в читаемый адрес

#### Настройка получателей и способов отправки
- **Выбор контактов**: предварительная настройка получателей
- **Способы отправки**: SMS, мессенджеры (WhatsApp, Telegram), email
- **Шаблоны сообщений**: настраиваемые тексты для разных языков

### Настройки приложения

#### Основные настройки
- **Выбор получателей**: список контактов для отправки координат
- **Способ отправки**: выбор метода передачи (SMS, мессенджер, email)
- **Язык интерфейса**: английский, немецкий, украинский
- **Чувствительность встряхивания**: настройка порога срабатывания

#### Настройки премиум-версии
- **Отключение диалогового окна**: опция полного отключения окна после отправки через ярлык
- **Отключение рекламы**: удаление рекламных блоков AdMob
- **Статус подписки**: отображение текущего статуса премиум-версии

### Монетизация

#### Реклама AdMob
- **Размещение**: только в диалоговом окне после отправки через ярлык
- **Размер**: нижняя четверть экрана
- **Типы**: баннерная реклама, соответствующая политикам AdMob
- **Детская аудитория**: соблюдение требований для контента, подходящего детям

#### Премиум-версия
- **Отключение рекламы**: полное удаление рекламных блоков
- **Отключение диалогов**: возможность работы только в фоновом режиме
- **Дополнительные функции**: расширенные настройки и возможности

### Локализация
- **Английский**: основной язык интерфейса
- **Немецкий**: полная локализация интерфейса и сообщений
- **Украинский**: полная локализация интерфейса и сообщений
- **Адаптация**: учет региональных особенностей форматов координат и адресов

## Нефункциональные требования

### Производительность
- **Скорость отправки**: координаты отправляются за <3 секунд
- **Время определения**: GPS-координаты получаются за <5 секунд
- **Отзывчивость UI**: диалоговое окно открывается мгновенно

### Точность и надежность
- **Точность GPS**: до 10 метров при хороших условиях
- **Фоновая работа**: стабильная работа датчика встряхивания
- **Обработка ошибок**: корректная работа при отсутствии сети/GPS

### Безопасность
- **Шифрование**: защита передаваемых координат
- **Разрешения**: минимально необходимые права доступа
- **Приватность**: соблюдение GDPR и местных законов

### Соответствие AdMob
- **Политики контента**: соблюдение всех требований AdMob
- **Детская аудитория**: контент, подходящий для семейного использования
- **Размещение рекламы**: четкое разделение контента и рекламы

## Платформа

### Целевые платформы
- **Android**: основная платформа (приоритет)
- **iOS**: вторая очередь разработки

### Технические требования
- **Android**: минимальная версия 7.0 (API 24)
- **iOS**: минимальная версия 12.0
- **Разрешения**: 
  - Геолокация (точная и приблизительная)
  - Датчики (акселерометр для встряхивания)
  - SMS (для отправки сообщений)
  - Контакты (для выбора получателей)
  - Интернет (для рекламы и мессенджеров)

### Интеграции
- **AdMob SDK**: для показа рекламы
- **Google Play Services**: для определения местоположения
- **Системные мессенджеры**: интеграция с установленными приложениями
- **SMS API**: для отправки текстовых сообщений

## Ограничения

### Технические ограничения
- **Батарея**: минимальное потребление в фоновом режиме
- **Память**: использование RAM <50MB
- **Хранилище**: размер приложения <20MB, данные <10MB
- **Трафик**: оптимизация передачи данных

### Соответствие требованиям
- **Google Play**: соблюдение политик магазина приложений
- **App Store**: соответствие требованиям Apple (для iOS версии)
- **GDPR**: защита персональных данных пользователей
- **COPPA**: безопасность для детской аудитории
- **AdMob**: строгое следование правилам размещения рекламы

### Функциональные ограничения
- **Частота отправки**: защита от спама (не чаще 1 раза в минуту)
- **Количество получателей**: максимум 5 контактов одновременно
- **Размер сообщений**: ограничение длины дополнительного текста
