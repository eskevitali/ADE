# Diktor

**ADI ID:** `8c206b97-76c1-46bb-844c-d8e0c60856d3`

## Idea

Мобильное Приложение для озвучивания текстовых файлов PDF, DOC, TXT.
Интерфейс простой: Загрузить документ в библиотеку приложения, для этого на устройстве создается папка . Дальше в библиотека выбирается нужный документ в активную область, где есть кнопка читать и кнопка диктор для озвучки. При чтении, это обычное чтение с скролингом построчно или страницами, а также масштаб. Так же есть чтение по словам, когда текст транслируется по словам с определенной частотой, которую читающий может выбрать ползунком внизу интерфейса окна. Также внизу есть кнопка читать и пауза, вернутся на строку/абзац/страницу назад. При паузе запоминается точка остановки чтения.
Режим слушать это аудио текст то спич. Он использует встроенную функцию мобильного устройства. В нем также есть режим паузы и прокрутки назад.
