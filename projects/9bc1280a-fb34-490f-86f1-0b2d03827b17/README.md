# Я ТУТ v3

**ADI ID:** `ad41334b-fb5f-4a53-94b1-554a6ad808ee`

## Idea

Я ТУТ v3 — утилитарное мобильное приложение (iOS/Android) для мгновенного захвата GPS-координат устройства и отправки их выбранному контакту в один клик. Контакт и способ отправки (SMS/WhatsApp/Telegram) задаются в настройках. Главный экран минималистичный: одна крупная кнопка «Я ТУТ» и иконка настроек.
