# Техническое задание (ТЗ)

## Цели
Создать простую Python функцию, которая выводит цветное приветственное сообщение с использованием ANSI escape-кодов или библиотеки colorama для кроссплатформенной совместимости.

## Пользователи
- Начинающие Python разработчики
- Студенты, изучающие основы программирования
- Разработчики, нуждающиеся в простом примере цветного вывода в консоль
- Пользователи, желающие сделать консольные приложения более привлекательными

## Функции
- Функция `hello()` без параметров
- Вывод приветственного сообщения "Hello, World!" в цвете
- Поддержка различных цветов текста (красный, зеленый, синий, желтый, пурпурный, голубой)
- Возможность вызова функции из любого места в коде
- Автоматическое восстановление стандартного цвета после вывода
- Кроссплатформенная поддержка цветов (Windows, Linux, macOS)

## Нефункциональные требования
- Совместимость с Python 3.x
- Простота и читаемость кода
- Поддержка цветного вывода в различных терминалах и консолях
- Graceful fallback для терминалов без поддержки цветов
- Минимальные внешние зависимости (предпочтительно использование colorama)

## Платформа
- Python 3.x
- Windows (Command Prompt, PowerShell, Windows Terminal)
- Linux (различные терминалы)
- macOS (Terminal, iTerm2)
- Поддержка IDE консолей (PyCharm, VS Code)

## Ограничения
- Использование стандартных методов цветного вывода (ANSI codes или colorama)
- Обеспечение читаемости цветного текста на различных фонах терминала
- Обработка случаев, когда терминал не поддерживает цвета
- Сохранение простоты для начинающих разработчиков
